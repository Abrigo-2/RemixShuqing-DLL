Made using [the Slugbase project template](https://github.com/SlimeCubed/ExampleSlugBaseMod/archive/refs/heads/master.zip)!!

The DLL adds the following features for the Shuqing slugcat:
- Whenever the Shuqing is exhausted, it will emit LizardBubbles, matching its "Spot" color property! This makes the exhaustion state more telling, the only sign used to be the light radius narrowing, which isn't noticeable in lit up areas without a background.
- An in-game tutorial regarding the jump boost mechanic! It plays upon entering LF_E05 during the story campaign.
